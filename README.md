# ig-content

Instagram（@556bear_556）の自動投稿用の素材置き場です。

- `content/*.json` … 投稿の中身（スライドの文章・リールの場面・キャプション）
- `tools/build.py` … 中身から画像（1080x1350）とリール動画（1080x1920）を作り、`manifest.json` に予定を書き込む
- `media/<id>/` … できあがった画像・動画
- `manifest.json` … 投稿予定表。エックスサーバーの igpost.py が1時間ごとに読み、時刻が来た投稿を行う

投稿枠：朝 7:55 カルーセル／昼 12:25 リール／夜 19:55 カルーセル（日本時間）
